# Vortex ID · Punta Alta

Asistente personal para Punta Alta: ficha médica de emergencia SOS, farmacias de turno con geolocalización y llamadas rápidas.

## Ejecutar localmente
1. `npm install`
2. Copiá `.env.example` a `.env.local` y completá las claves.
3. `npm run dev`

## Compilar
`npm run build`
